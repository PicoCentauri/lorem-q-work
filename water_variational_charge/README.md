# water_variational_charge

Core test of whether a model can get total charge right on genuinely
non-local grounds: a cutoff-based potential could infer charge by counting
H atoms at equilibrium, but must fail once a cluster dissociates beyond
that cutoff. QEq-style long-range models' main failure
mode here — overestimated intermolecular charge transfer and spurious
energy fluctuations in the dissociation limit.

## Source

Vondrák, Reuter & Margraf, ["Pushing charge equilibration-based machine
learning potentials to their limits"](https://doi.org/10.1038/s41524-025-01791-3),
*npj Comput. Mater.* **11**, 288 (2025).

## Computational details

Water clusters of 3–10 molecules (from Xantheas' atlas of minima), in three
net charge states: neutral, protonated (+1, via added H⁺) and deprotonated
(−1, via removed OH). Non-equilibrium geometries generated by GFN2-xTB MD at
300 K, plus isotropic expansion/contraction (0.9×–5.0× the equilibrium
cluster) to push molecules beyond any reasonable descriptor cutoff.
Energies, forces and Hirshfeld charges from FHI-aims, hybrid PBE0 functional,
*tight* basis/integration settings. Isolated (`pbc="F F F"`, no lattice).

## How to read the data

```python
from ase.io import read

frames = read("water_variational_charge/water_variational_charge_train.xyz", index=":")
atoms = frames[0]
forces = atoms.arrays["forces"]      # eV/Å
charges = atoms.arrays["charges"]    # Hirshfeld, per atom
energy = atoms.info["energy"]        # eV
tot_charge = atoms.info["tot_charge"]  # e, in {-1, 0, +1}
```
